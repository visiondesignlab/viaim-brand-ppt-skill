# 30 页全版式示例

这个目录同时提供网页演示版和原生可编辑 PowerPoint 版：

- [`index.html`](./index.html)：保留横向翻页、低功耗模式、总览和演讲者模式。下载整个目录后用浏览器打开，或在目录内启动任意静态服务器。
- [`viaim-brand-ppt-test-30p-editable.pptx`](./viaim-brand-ppt-test-30p-editable.pptx)：30 页、30 页演讲者备注，文字、色块、线条、卡片与数据条保持独立可编辑；可直接用 Windows PowerPoint、macOS PowerPoint 或 Keynote 打开。

HTML 中的图片、Logo 与 Motion One 离线副本均使用相对路径，请保留 `assets/` 和 `images/` 子目录。页面中的数据为版式演示数据，不代表真实业务统计。
