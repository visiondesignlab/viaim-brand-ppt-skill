# 中文 PPT 排版规则

本规则把 W3C《中文排版需求》（CLReq）和《中文文案排版指北》收敛成适用于 16:9 横排演示文稿的可执行约束。来源：

- https://www.w3.org/TR/clreq/
- https://github.com/aaranxu/chinese-copywriting-guidelines

## P0 · 交付前必须通过

1. **行首行尾禁则**：顿号、逗号、句号、冒号、分号、叹号、问号、结束引号、结束括号、结束书名号、连接号、间隔号、分隔号不得出现在行首；开始引号、开始括号、开始书名号不得出现在行尾。
2. **符号不可拆分**：破折号和省略号视为整体；阿拉伯数字不得在内部换行；百分号、千分号、度数符号与其前面的数字不得拆行；正负号与后面的数字、货币符号与数字不得拆行。
3. **孤字不成行**：段落或标题末行只有一个汉字，或一个汉字加标点，视为失败。优先改写，其次调整文本框宽度或字号；标题行高仍保持 130%。
4. **中文与英文之间加半角空格**，中文与阿拉伯数字之间加半角空格，数字与单位之间加半角空格；百分比和角度不加空格。
5. **全角标点**：中文句子使用全角中文标点，横排引号使用弯引号；全角标点与相邻字符之间不加空格。完整英文句子和英文专名内部使用半角标点。
6. **数字使用半角字符**；专有名词保持官方大小写，例如 `GitHub`、`WebGL`、`HTML`、`viaim`。
7. **不重复标点**：除表达确有需要的 `？！` 外，不连续堆叠问号或叹号。

## CSS 基线

```css
.slide{
  line-break:strict;
  word-break:normal;
  overflow-wrap:break-word;
  text-autospace:normal;
}
.keep-together{white-space:nowrap}
```

`text-autospace` 属于渐进增强；不能假设所有浏览器都已自动补空格，所以源文案本身必须写对。

## PPT 专项处理

- 页面标题、引语、结论句按视觉行人工检查；不能只相信 DOM 中的 `<br>`。
- 为数值、单位、百分号、版本号和中英文专名增加 `.keep-together`，避免符号或词组被拆开。
- 中文正文默认左对齐；不为了两端对齐而拉伸英文单词或阿拉伯数字内部字距。
- 标点挤压属于排版引擎能力。网页 PPT 不具备可靠挤压时，采用“先改写、再调整宽度、最后轻调字号”的人工策略。
- `<br>` 只能用于语义分段或受控标题换行，不能制造行首标点、行尾开括号或孤字。

## 校验

```bash
node scripts/validate-chinese-typesetting.mjs path/to/index.html
node scripts/validate-title-wrap.mjs path/to/index.html
```

只有同时输出 `CHINESE_TYPE_OK` 与 `TITLE_WRAP_OK`，且浏览器截图检查无行首/行尾禁则问题，才能交付。
